#Descripción
ClubLectura es una aplicación desarrollada en Android Studio con Jetpack Compose, diseñada para permitir a los usuarios inscribirse en un club de lectura. 
La app cuenta con tres pantallas principales:
- Pantalla de presentación con un botón para iniciar la inscripción.
- Formulario de inscripción, donde el usuario ingresa su nombre, elige su género literario favorito y decide si quiere recibir recomendaciones.
- Pantalla de confirmación, que muestra los datos ingresados.
